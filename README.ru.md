# DesktopPanel

[English](README.md)

Панель-оверлей для Windows 10/11. Открывается по сочетанию клавиш поверх любого окна или полноэкранной игры
и закрывается без переключения из неё.

## Возможности

- **Рабочий стол** — ярлыки рабочего стола в панели: группы (папки), свой порядок, имена и картинки, поиск по системе
  (индекс поиска Windows), корзина, отмена (Ctrl+Z). Значки настоящего рабочего стола можно скрыть.
- **Мини-браузер** — окно WebView2 поверх всех окон. Режимы: сквозной клик, взаимодействие, перемещение.
- **Zapret** — загрузка и управление [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube):
  запуск/остановка, служба Windows, тест стратегий, списки, диагностика. По умолчанию выключен.
- **Прокси для Telegram** — локальный [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy).
- **HDR** — включение/выключение и яркость SDR-содержимого.
- **Диспетчер задач** — процессы, ЦП, память, диск, сеть.
- **Уголок** — панель сворачивается в небольшой угол с кнопками.
- **Сочетания клавиш** — панель, действия (уголок, настройки, диспетчер задач, корзина, поиск, Zapret, прокси Telegram,
  HDR, значки) и мини-браузер. Кнопки мыши (колесо, боковые, прокрутка) — с Ctrl/Alt/Shift/Win. По умолчанию
  назначено только сочетание панели.
- Языки интерфейса: русский, английский.

## Требования

- Windows 10 2004 (сборка 19041) и новее, Windows 11; x64.
- Microsoft Edge WebView2 Runtime (в Windows 11 уже установлен) — для мини-браузера.
- Права администратора: нужны Zapret (драйвер WinDivert, служба), HDR и файлу hosts.

## Установка

1. Скачать `DesktopPanel.exe` из [Releases](../../releases). Один файл, .NET не нужен.
2. Запустить. Файл без цифровой подписи, поэтому SmartScreen может показать «Система Windows защитила ваш компьютер»:
   **Подробнее → Выполнить в любом случае**.
3. Мастер первого запуска настраивает язык, Zapret, сочетание и автозапуск. Повторный запуск — из настроек.

Сочетание по умолчанию: **Win+C**. Windows держит его за собой; программа предлагает забрать его
(настройка «Забирать сочетание у Windows» — низкоуровневый хук клавиатуры, только для выбранных сочетаний).

## Данные

| Путь | Что там |
|---|---|
| `%APPDATA%\DesktopPanel\config.json` | настройки |
| `%APPDATA%\DesktopPanel\logs\` | журналы |
| `C:\ProgramData\DesktopPanel\zapret\` | Zapret (только если включён) |

Автозапуск — задание Планировщика. Удаление — Настройки → Удаление → «Удалить программу» или «Установленные приложения» Windows.

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```
dotnet publish src\DesktopPanel\DesktopPanel.csproj -c Release -o dist
```

Результат: `dist\DesktopPanel.exe` (самодостаточный, один файл). Или `build.bat`.

Зависимости (NuGet): Microsoft.Web.WebView2, NAudio.Wasapi, System.Data.OleDb. Лицензии: [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
